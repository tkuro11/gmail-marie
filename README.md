gmailのメールボックスから特定のクエリ条件に合致するものを全部消すアプリ．

[^1]: 名前は近藤麻理恵さんの「『人生がときめく片づけの魔法』から

## 使い方
1. GoogleのAPIキーを取得する
    1. Cloud console(https://console.cloud.google.com/?hl=ja)にログインして[APIとサービス]に進む（必要に応じてprojectを作る）
    1. サイドメニューの[ライブラリ]をクリックして「Gmail API」を検索して選択する．[有効にする]をクリック.
    1. [認証情報]タブを選ぶ．[認証情報を作成]ポップダウンから[OAuthクライアントID の作成]を選ぶ．
    1. [アプリケーションの種類]を[デスクトップアプリケーション]で[作成]をクリック（名前は任意で良い）
    1. 「OAuth クライアントを作成しました」が表示される．[JSONをダウンロード]から認証情報をダウンロード（後からできない）し，名前をcredentials.jsonにしてこのフォルダに保存する．
2. アプリを実行する
    1. uvがインストールしてあることを確認し，以下のようにライブラリの同期をとる．(一度だけ)
    ```bash
    % uv sync
    ```
    2. 以下のようにパターンを引数に実行する．
    初回実行時はブラウザが立ち上がり，認証を要求されるので，それに従う．
    「このアプリを信頼しますか？」は「続行」を選択．
    ```bash
    % uv run gmail-marie.py <fromのパターン>
    ```
    3. 検索結果が一覧表示され，確認メッセージが出るので，問題なければ'y'を入力すると削除される．'n'でキャンセル．
